[![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.x-6DB33F?style=flat-square&logo=springboot&logoColor=white)](https://spring.io/)
[![Kafka](https://img.shields.io/badge/Kafka-231F20?style=flat-square&logo=apachekafka&logoColor=white)](https://kafka.apache.org/)
[![React](https://img.shields.io/badge/React-18.x-61DAFB?style=flat-square&logo=react&logoColor=black)](https://react.dev/)
[![Grafana](https://img.shields.io/badge/Grafana-F46800?style=flat-square&logo=grafana&logoColor=white)](https://grafana.com/)

### [`ShieldComment`](https://github.com/julianReyes-dev/ShieldComment)

### [`fastapi-rabbitmq-traefik`](https://github.com/julianReyes-dev/Parcial2_Corte2_Distri)
[![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)](https://fastapi.tiangolo.com/)
[![RabbitMQ](https://img.shields.io/badge/RabbitMQ-FF6600?style=flat-square&logo=rabbitmq&logoColor=white)](https://www.rabbitmq.com/)
[![Docker](https://img.shields.io/badge/Docker-Compose-2496ED?style=flat-square&logo=docker&logoColor=white)](https://www.docker.com/)

Local microservices architecture with FastAPI, RabbitMQ, and Traefik, orchestrated with Docker Compose. Implements path-prefix routing, durable queues, and a Python worker that persists messages to disk.

---

### [`AcademiaCore`](https://github.com/julianReyes-dev/academiacore)
[![Flask](https://img.shields.io/badge/Flask-3.0-000000?style=flat-square&logo=flask&logoColor=white)](https://flask.palletsprojects.com/)
[![MongoDB](https://img.shields.io/badge/MongoDB-Atlas-47A248?style=flat-square&logo=mongodb&logoColor=white)](https://www.mongodb.com/atlas)

Full-stack academic management system for universities. Covers CRUD for teachers, students, and courses; atomic-transaction enrollment in MongoDB; bulk JSON import; statistical reports; and role-based access control.

---

### [`EpiSim`](https://github.com/julianReyes-dev/EpiSim)
[![Python](https://img.shields.io/badge/Python-3.8+-3776AB?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)

Monte Carlo simulation of the SEIR epidemic propagation model. Implements a linear congruential generator validated against six statistical tests (Kolmogorov-Smirnov, Runs, Poker, etc.), sensitivity analysis, and vaccination vs. no-vaccination comparison across 1,000 independent runs.

---

### [`journaling-fs-simulation`](https://github.com/julianReyes-dev/journaling_simulation)
[![Python](https://img.shields.io/badge/Python-3.8+-3776AB?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)

Educational simulation of a journaling file system (Write-Ahead Logging). Quantitatively demonstrates the recovery improvement (+20–50%) that journaling provides over non-journaling systems, with comprehensive unit tests.
